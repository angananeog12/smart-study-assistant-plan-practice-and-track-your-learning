# smart-study-assistant-plan-practice-and-track-your-learning

## Overview of the project

Smart Study Assistant Plan , Practice and Track Your Learning is a Python-based application designed to help students organize their study activities, practice through test, analyze their performance, and receive study recommendations.

The project combines study planning, test-based assessment, progress analysis, and personalized study recommendations in a single application.

## Features

* Student information management
* Study planning based on their course and semester
* Test-based practice
* Automatic test score calculation
* Progress and performance analysis
* Study recommendations based on performance
* Modular Python project structure

## Technologies Used

* Python
* Git
* GitHub
* Visual Studio Code

## Description of Modules

### Student Module

Collects and displays basic information about the student.

### Planner Module

Allows the student to enter a subject and planned study hours and provides a simple study-time recommendation.

### Test Module

Provides quiz questions and calculates the student's score.

### Performance Module

Analyzes the quiz score and provides a performance category.

### Marks Module

Provides study suggestions based on the student's performance and study plan.
