# Smart Study Assistant

## Overview

Smart Study Assistant is a Python-based application designed to help students organize their study activities, practice through quizzes, analyze their performance, and receive study recommendations.

The project combines study planning, quiz-based assessment, progress analysis, and personalized study recommendations in a single application.

## Features

* Student information management
* Study planning based on subject and study hours
* Quiz-based practice
* Automatic quiz score calculation
* Progress and performance analysis
* Study recommendations based on performance
* Modular Python project structure

## Technologies Used

* Python
* Git
* GitHub
* Visual Studio Code

## Description of Modules

### Student Management

Collects and displays basic information about the student.

### Study Planner

Allows the student to enter a subject and planned study hours and provides a simple study-time recommendation.

### Quiz Module

Provides quiz questions and calculates the student's score.

### Progress Analyzer

Analyzes the quiz score and provides a performance category.

### Recommendation Module

Provides study suggestions based on the student's performance and study plan.

## Installation

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. No external Python libraries are required for the basic version.

## How to Run

Open the project folder in Visual Studio Code and run:

```bash
python main.py
```

Follow the instructions displayed in the terminal.

## Testing

The application can be tested using different student details, study hours, and quiz answers.

Different quiz scores should produce different performance categories and study recommendations.
